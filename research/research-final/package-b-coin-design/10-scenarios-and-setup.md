# 10 Scenarios and Setup

Status: rules draft. Every setup value is a design value, not a historical deployment (DD-15.2; M-028). Values marked [tune] need playtest calibration. Each basis note gives the evidence for the direction of a value and a confidence level for the historical calibration. Thresholds come from 09, section 2.

General setup steps for every scenario:

1. Build only the scenario's piles (05, section 1.1). Stack them in Campaign order.
2. Place pieces, markers and tracks from the scenario tables.
3. Put all other pieces in Available, except Village Guards before Law 3175 (Out of Play). All Guerrillas start Underground (CT 1.4.3).
4. Give each faction the Pivotal Events listed for the scenario.
5. Compute Control, scores and Harm counts. Check them against the table totals.
6. The PKK is First Eligible (DD-04.6). Reveal the first card.

## 3. Scenario A: 1984-1989 (C1 and C2)

Start 15 Aug 1984. Use the full campaign setup (section 2) without change. Build piles C1 and C2 only. The second Propaganda round is the final round.

Pivotal Events: State none; PKK ARGK Formed. The State has no Pivotal in this period, which matches a thin early response [F-010; Q-184]. Test whether the State needs one.

Thresholds: 49 and 30 (easy-ceiling rule, 09 section 2.1). Start margins -28 and -26. Expect the game to end on margins.

Question the scenario tests: can a small opening force grow when the State has few local tools, and do Guards after Law 3175 change that? [E-0004; F-010; F-011]

## 6. Between-Campaign structural changes

Structural change sits in the rules, not in a fixed snapshot (DD-01). It comes from two sources: mandatory structural cards in each pile (05, section 1.1) and switches at each Reset.

### 6.1 Mandatory structural cards

Each card's "Always" line applies when the card is revealed, whether or not anyone executes its Event (05, section 5).

| Campaign | Card | Always line | Evidence |
|---|---|---|---|
| C1 | Law 3175 | Move all 16 Village Guards from Out of Play to Available | E-0004; E-0005; F-010 |
| C1 | KDP Orders PKK Out | If KDP is Host, set it to Tolerant | E-0160; F-022 |
| C2 | OHAL | If Emergency Rule is Martial Law, set it to OHAL | E-0055; F-013 |
| C2 | Syria Security Protocol | If Syria is Host, set it to Tolerant | E-0170; F-020 |

## 8. Tests

1. Play each short scenario twice with sides swapped. Record start and final margins.
2. For the campaign, record the first round in which either faction qualifies. A win before the C3 Propaganda round in more than one game in five suggests thresholds are too low.
3. Check that each mandatory card's Always line fires once and only once.
